# AI/ML Engineering

A growing collection of notebooks covering the tools, libraries, and
concepts behind AI, Machine Learning, and Deep Learning written to be
read from scratch to advanced, in plain language, with runnable code.


## What's in here so far

| Notebook | Covers |
|---|---|
| [`Pandas_A_to_Z.ipynb`](./pandas/Pandas_A_to_Z.ipynb) | Data loading, cleaning, indexing, GroupBy, merging, reshaping, time series, performance |
| [`NumPy_A_to_Z.ipynb`](./numpy/NumPy_A_to_Z.ipynb) | Arrays, indexing, broadcasting, vectorization, linear algebra, random sampling |
| [`Matplotlib_A_to_Z.ipynb`](./matplotlib/Matplotlib_A_to_Z.ipynb) | Core plotting concepts, EDA plots, and ML-specific plots (loss curves, confusion matrices, ROC curves) |


## Planned additions

More notebooks on core ML/DL topics like scikit-learn, TensorFlow/PyTorch,
model evaluation, feature engineering, and other tools in the AI/ML
pipeline will be added here as they're completed.


Each notebook is self-contained — no external datasets are needed to run
the examples.
